## 📖 О приложении

**Планер** — это веб-приложение (PWA) для планирования недели. Открывается в браузере, ставится на домашний экран как обычное приложение и работает полностью офлайн.

**Никакой регистрации. Никакой рекламы. Никакой отправки данных в интернет.** Все дела хранятся в локальном хранилище браузера на вашем устройстве.

## ✨ Возможности

### 🗓 Неделя
- Сетка на 7 дней — вся неделя помещается на экране, без пролистывания
- Навигация стрелками ‹ › по предыдущим и будущим неделям
- Возврат к текущей неделе одним нажатием на дату
- В карточке дня — первые 3 дела и пометка «ещё N дел»
- Сегодняшний день выделен синим градиентом

### ☀️ Сегодня
- Отдельная вкладка с делами на текущий день
- Быстрое добавление дела с полем времени
- Отметка «выполнено» — невыполненные всегда сверху

### 🕒 Время и сортировка
- У каждого дела есть **необязательное** поле времени
- Дела со временем сортируются по часам, без времени — уходят в конец
- Время можно добавить при создании дела или поменять позже, прямо в редакторе

### 📅 Экспорт в календарь
- Кнопка «📅 В календарь» создаёт файл `.ics`
- На iPhone открывается в Calendar → добавляется событие с напоминанием за 15 минут
- Дело со временем → событие в конкретное время
- Дело без времени → событие на весь день

### 🎨 Интерфейс
- Тёмная тема, аккуратные скругления, крупные кнопки под палец
- Всё помещается на iPhone без горизонтальной и вертикальной прокрутки
- Поддержка safe-area (вырез, домашний индикатор)

### 💾 Резервное копирование
- Кнопка ⇅ открывает панель бэкапа
- Копирование JSON в буфер, скачивание файлом, загрузка и восстановление
- Данные хранятся в `localStorage` и привязаны к домену — сохраняйте бэкап время от времени

## 📥 Установка на iPhone

1. Откройте приложение в **Safari**: 👉 [stuma467.github.io/planer-pwa](https://stuma467.github.io/planer-pwa/)
2. Нажмите **«Поделиться»** → **«На экран Домой»**.
3. Назовите — например, «Планер» — и добавьте.

Запускается с домашнего экрана как обычное приложение, без адресной строки Safari. Работает офлайн.

## 📥 Установка на Android

1. Откройте приложение в **Chrome**: 👉 [stuma467.github.io/planer-pwa](https://stuma467.github.io/planer-pwa/)
2. Меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).

## 🛠 Технологии

- **Vanilla JavaScript** — без сборщиков и зависимостей
- **CSS Grid + Flexbox** — сетка недели в две колонки, всё на одном экране
- **localStorage** — хранение дел на устройстве
- **Service Worker** (network-first для HTML/JS) — офлайн-режим и мгновенное обновление версий
- **Web App Manifest** — установка как PWA с иконкой
- **iCalendar (.ics)** — экспорт дел в календарь
- Хостинг: **GitHub Pages**

## 🔒 Приватность

Все данные хранятся локально в браузере на вашем устройстве. Приложение не собирает статистику, не показывает рекламу и не передаёт данные в интернет. Единственный сетевой запрос — загрузка самих файлов приложения при первом открытии.
